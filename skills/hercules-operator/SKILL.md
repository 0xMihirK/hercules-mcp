# Hercules operator

Use this skill for assessment-wide decisions; a narrow task may need only the matching domain skill. Establish the permitted target, techniques, and stop conditions. Read existing objectives, notes, and artifacts before making a new Docker-backed call. Choose the narrowest exposed structured tool, reuse the current container while work is active, and save raw evidence before filtering. Coordinate workers before stopping or rotating a session. An artifact or exit code alone never proves a finding.

## Select one topic

- [Fast, reliable hypothesis checks](references/fast-checking.md)
- [Evidence-led security reporting](references/reporting.md)

The reference is guidance, not authorization. Check the current MCP schema and installed backend before executing a suggested route. If a prerequisite is absent, report the coverage gap instead of inventing a tool or widening scope.

## Finish

Close owned jobs, preserve useful artifacts and notes, and stop the container only when no parallel worker still needs it. Confirm the stop response; report any unverified cleanup.
