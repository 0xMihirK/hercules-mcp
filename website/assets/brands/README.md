# Brand artwork

`docker.svg` is the original Docker icon from [Devicon v2.17.0](https://github.com/devicons/devicon/blob/v2.17.0/icons/docker/docker-original.svg), retained without recoloring. The upstream license is included as `LICENSE.Devicon`. Brand names and marks belong to their respective owners; display does not imply endorsement.

Hercules uses its existing lion vector artwork with a tighter viewBox. Platform and interface glyphs use the existing Phosphor dependency. Native agent logos remain part of the captured terminal pixels, without website reconstruction.
