# Brand artwork

`docker.svg` and the Windows 11, Apple, and Linux platform marks are from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons). The upstream license is included as `LICENSE.Devicon`. Brand names and marks belong to their respective owners; display does not imply endorsement.

The architecture diagram uses these client marks in their original colors to identify compatible agents:

- `claude.svg`: [Claude site favicon](https://claude.ai/favicon.svg).
- `cursor.svg`: [Cursor site favicon](https://cursor.com/favicon.svg); see [Cursor's brand guidance](https://cursor.com/brand).
- `codex.png`: 96px downscale of the Codex app icon [documented and redistributed here](https://github.com/backnotprop/orchestrator/blob/main/assets/providers/README.md) as an extraction from OpenAI's Codex app; see [OpenAI's mark guidance](https://openai.com/brand/).
- `hermes.png`: [Hermes Agent site icon](https://hermes-agent.nousresearch.com/assets/hermes-agent/icon.png).

Brand names and marks belong to their respective owners; display does not imply endorsement. Hercules uses its existing lion vector artwork with a tighter viewBox. Interface glyphs use the existing Phosphor dependency.
