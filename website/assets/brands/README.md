# Brand artwork

`docker.svg` and the Windows 11, Apple, and Linux platform marks are from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons). The upstream license is included as `LICENSE.Devicon`. Brand names and marks belong to their respective owners; display does not imply endorsement.

Hercules uses its existing lion vector artwork with a tighter viewBox. Interface glyphs use the existing Phosphor dependency. Native agent logos remain part of the captured terminal pixels, without website reconstruction.
