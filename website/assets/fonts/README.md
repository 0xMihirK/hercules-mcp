# Self-hosted font assets

Downloaded from the official Google Fonts service. Each font retains its SIL Open Font License in this folder. Font assets are Latin subsets.

- `archivo-latin-variable.woff2`: Archivo, weight 100–900, width 87.5% (semi-condensed).
- `ibm-plex-sans-latin-variable.woff2`: IBM Plex Sans, variable weight; used at 400 and 500.
- `ibm-plex-mono-latin-400.woff2`: IBM Plex Mono Regular.
- `ibm-plex-mono-latin-500.woff2`: IBM Plex Mono Medium.

Sources:

- https://github.com/Omnibus-Type/Archivo
- https://github.com/IBM/plex
- https://github.com/google/fonts/tree/main/ofl/archivo
- https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono
